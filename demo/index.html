Install & configure

Copy the snippet for your stack, then tune any option below. Every default is already WCAG-safe — you're only adjusting behavior, not accessibility.

Shopify theme

No npm, no build step. In layout/theme.liquid:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@ada-ally/slider@0.1/dist/adaally-slider.css">
<script src="https://cdn.jsdelivr.net/npm/@ada-ally/slider@0.1/dist/adaally-slider.umd.js" defer></script>

Then in any section or snippet:

<div data-adaally-slider='{"autoplay": true}'
     aria-label="{{ section.settings.title }}">
  {% for block in section.blocks %}
    <img src="{{ block.settings.image | image_url: width: 1600 }}">
  {% endfor %}
</div>

npm / bundler

React, Vue, Next.js, Vite — anything with a build step.

npm install @ada-ally/slider
import AdaallySlider from '@ada-ally/slider';
import '@ada-ally/slider/css';

new AdaallySlider('#hero', {
  autoplay: true,
  dotsShape: 'line',
});

Plain HTML

WordPress, static sites, prototypes — any page, no bundler.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@ada-ally/slider@0.1/dist/adaally-slider.css">
<script src="https://cdn.jsdelivr.net/npm/@ada-ally/slider@0.1/dist/adaally-slider.umd.js" defer></script>

<div data-adaally-slider='{"autoplay": true}'>
  <img src="1.jpg">
  <img src="2.jpg">
  <img src="3.jpg">
</div>

All options

Pass any of these as the second argument to new AdaallySlider(el, options), or as JSON in data-adaally-slider='{...}' for auto-init.

OptionTypeDefaultWhat it does
autoplaybooleanfalseAuto-advance slides. Forces a visible pause button.
intervalnumber (ms)5000Delay between auto-advances.
loopbooleantrueWrap around at the ends. If false, prev/next disable at the boundaries.
keyboardbooleantrueEnable arrow-key / Home / End navigation on controls.
pauseOnHoverbooleantruePause autoplay while the pointer is over the slider.
pauseOnFocusbooleantruePause autoplay while focus is inside the slider.
showArrowsbooleantrueRender prev/next buttons.
showDotsbooleantrueRender dot pagination.
slidesPerViewnumber | breakpoint map1Slides visible at once. Pass a map for responsive: {0:1, 640:2, 960:3} (keys are min-width in px).
slidesToScrollnumber1Slides advanced per prev/next step.
transition'slide' | 'fade''slide'Translated flex track vs. stacked cross-fade.
labelstring—Sets aria-label on the root — the carousel's accessible name.
icons{ prev?, next?, play?, pause? }{}Custom SVG/HTML strings, overriding the default icons one by one.
revealControlsbooleanfalseHide arrows and play/pause until hover or focus-within. Touch devices always show.
playButtonPosition6 positions'top-left'top-left, top-center, top-right, bottom-left, bottom-center, bottom-right.
dotsShape'dot' | 'line''dot'Circular dots or thin horizontal bars.
dotsPosition'overlay' | 'below''overlay'Float over the bottom of the slide, or sit in a block below the whole slider.
labelsobjectsee READMEOverride every ARIA string for i18n, including the live-region announcement functions.
